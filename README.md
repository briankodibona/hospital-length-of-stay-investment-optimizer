# Hospital Length of Stay Investment Optimizer

A healthcare analytics project focused on identifying operational investments that can reduce average hospital patient length of stay.

## Overview

This project models the relationship between hospital resource allocation and patient stay duration using interpretable regression techniques and exploratory analysis.

The objective is to help healthcare administrators prioritize investments with the highest operational impact.

## Features

- Exploratory data analysis on hospital operational metrics
- Regression modelling for stay duration prediction
- Investment impact ranking
- Executive-focused visualizations
- Recommendation summary for stakeholders

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Business Questions

- Does scanner availability affect hospital stay duration?
- Which investments produce the highest reduction in length of stay?
- Which operational constraints create patient bottlenecks?

## Results

The analysis showed strong relationships between operational capacity indicators and patient stay duration, allowing investment priorities to be ranked using interpretable models.
