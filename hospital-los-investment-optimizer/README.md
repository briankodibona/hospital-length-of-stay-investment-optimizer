# Hospital Length of Stay Investment Optimizer

**Portfolio track:** Healthcare Analytics  
**Stack:** Python, pandas, scikit-learn, matplotlib

## Problem
This project turns a business or technical problem into a reproducible analytics workflow suitable for a portfolio case study.

## What the project does
- Loads or creates a realistic sample dataset.
- Performs exploratory analysis and feature engineering.
- Builds a model, scoring system, dashboard-ready output, or report.
- Exports charts and CSV summaries into the `outputs/` folder.
- Includes assumptions, limitations, and next steps for stakeholder discussion.

## Repository structure
```text
hospital-los-investment-optimizer/
├── data/          # sample input data
├── docs/          # report notes / methodology
├── outputs/       # generated charts, reports and tables
├── src/           # source code
├── README.md
└── requirements.txt
```

## How to run
```bash
pip install -r requirements.txt
python src/analyze_los.py
```

## Portfolio talking points
- Clear business framing.
- Reproducible Python workflow.
- Explainable outputs, not just code.
- Honest limitations and improvement ideas.

## Limitations
The included dataset is synthetic and designed for demonstration. A production version would require validated data governance, domain review, and proper deployment controls.
